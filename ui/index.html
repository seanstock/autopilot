Settings

Engines

Each engine is a CLI on this machine, signed in to its own subscription account. Autopilot never sees the credentials: it only runs the CLI. Sign in opens the CLI's own browser flow.

Provider API keys

Stored in ~/.autopilot/keys.json on this machine only, never in the registry, a log, or the UI. OpenRouter is what the OpenRouter engine runs on (Gemini, Grok, Qwen, DeepSeek, Kimi, GLM...). OpenAI is Codex's fallback when it is not signed in to ChatGPT, and reaches a project's own code as OPENAI_API_KEY. Claude cycles always stay on the Anthropic subscription. Detect looks in this machine's environment and nearby .env files and fills empty slots.

Projects folder

Where the Browse button starts when you add a project. Project directories are always local paths on the machine running the daemon.

Notifications

Optional webhook: Autopilot POSTs {title, body, t} JSON when it resumes after a usage window resets. Desktop toasts are always on.

Sharing this

Autopilot is local-first. Nothing is shared between machines: the daemon, the UI on port 4680, the registry in ~/.autopilot/ and every project directory live on the machine running it. To set up your own copy:

  1. Install Node 22+ and git.
  2. Install the engine CLI you want: npm i -g @anthropic-ai/claude-code or npm i -g @openai/codex.
  3. Clone the repo and run node autopilot.js. The daemon starts and this page opens.
  4. Open Settings and click Sign in next to your engine. It uses your own subscription account.
  5. Optionally set a Projects folder above.
  6. Click + Add project, choose a directory and write the mission prompt.
